# Crafting Interprete.rs

Working through Nystrom's excellent book [Crafting Interpreters](https://craftinginterpreters.com/), except instead of its original Java, I'm writing my interpreters in Rust.

This learning project came about from trying to devise a custom markup language for branching dialogue in interactive fiction. I wanted something similar to Markdown, with minimal syntax, but with support for branching logic. This is an attempt to learn more about the structure of language to see if I have the capacity to build this. And if not, then I'll have gained some very valuable skills.
